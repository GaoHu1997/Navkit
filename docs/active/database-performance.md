# 数据库链路性能优化

## 范围
同步全量/增量、SQL文件运行/恢复、逻辑备份；原生SQLite/MySQL/PostgreSQL优先。保持用户现有工作树改动。

## 非目标
不修改生产数据库持久化/约束，不以关闭fsync、丢数据或改变任意SQL事务语义换取速度；不把模拟数据库当实库；不在无Navicat实测时宣称优于Navicat。

## 验收标准
- 保存当前工作树优化前基线，较大数据集、多轮真实数据库前后对照，记录耗时/吞吐/行数/正确性。
- 产品实际路径有回归测试，覆盖类型、事务、错误、取消和恢复等受影响边界。
- 检查构建，测试失败如实记录；提供复现命令。
- 测试只使用新建隔离资源，结束后清理。
- Navicat若可用，同环境同数据同语义实测；若不可用，列为未完成对比，不能以原生客户端替代竞品结论。
