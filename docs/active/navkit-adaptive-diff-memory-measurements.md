## 来源与验收

以下原始观测来自82个成功新进程，附SHA256和定位行号：[完整来源](<evidence/adaptive-diff-20261114/final-benchmark-records.log#L1-L247>)。`memory=null`表示旧路线未导出预算账本，不是0内存。生成器还明确验证源/目标行数、missing/extra/changed和完整主键样本；足额10万行必须zero spill。

预算的作用是内存够时不落盘，额度不足付出磁盘成本；降低硬件available/压力时不可强行提高上限。该统计不把速度百分比外推为普遍保证，不承诺严格OS/RSS硬限制。
