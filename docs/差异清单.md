## 五、无法完全还原之处（如实说明）

1. 文字渲染：参考为 GDI ClearType（带彩色次像素边），WebView2 为 DirectWrite 灰度 AA，
   逐像素必然存在 1px 级差异 —— 该部分差异不可避免，几何与字号已对齐。
2. Ribbon 尾部按钮 ±10px 节距漂移（见上 1 条）；参考程序按钮为内容自适应宽度，实现取等距模型。
3. 演示数据状态（树展开深度、标签页集合）以截图为准做了复现，但截图间的状态差异
   （如 11/13 号截图的 SQL Server 页与展开树）未全部覆盖为演示分支。
4. 13 号截图右侧「表列表面板」与 12 号「执行中」状态：功能存在、状态未进入演示路径。
