## 4. 测试总结

- **用例总数 187；通过 185；失败 0；未测试 2**（DDB 写/改/删一组，原因=D3 环境限制；另有 MongoDB+91 类数据源无真实服务器未测试，原因见矩阵）。
- **覆盖**：7 个顶级菜单全部子项（含禁用态/快捷键/勾选态）、数据源选择器 102 类（含驱动状态徽标）、树/标签页/网格/查询页/右键菜单/边界输入/状态栏。
- **真实数据核对链**：MySQL CLI、psql、sqlite3(hex)、redis RESP、rqlite HTTP、etcdctl、DynamoDB Local HTTP、InfluxDB HTTP、VM API、Java H2 Shell —— 每一步写/改/删都有数据库侧独立核对。
- **Top 风险**：
  1. D1 类 CSS 缺失型缺陷说明样式回归缺少"几何级"断言，建议为标题栏/菜单栏加布局快照测试；
  2. DynamoDB Local 环境脆弱（unsigned/签名形态敏感、写入偶发静默丢失），建议验收固定使用官方 docker 或文件模式并全程使用完整 SigV4 形态头；
  3. 91 类无服务器数据源占比高，后续可通过同类协议桩服务扩大真实覆盖（但不得以同族实例冒充）。
