## 相对 v1 的关键改动

1. **六条横栏 → 四条**：菜单并入标题栏（38px），Ribbon 改为 46px 命令条，省下约 50px 垂直空间。
2. **三套图标 → 一套**：彩色伪 3D Ribbon 图标全部退役，统一 24 网格 / 1.75 描边 / currentColor 线性图标族（64 个）。
3. **五档近似字号 → 五级明确字号**：11 / 12 / 13 / 15 / 18，每级职责唯一。
4. **状态分层**：hover 灰底 → selected 浅蓝底 + 强调文字 → active 强调实底，不再全用 `#CCE8FF`。
5. **网格重做**：行高 19.2 → 28px，加斑马底、悬停、选中分层；数字列 `tabular-nums` 右对齐；NULL 降级斜体。
6. **信息面板分组化**：对象头 / 连接引用 / 分组键值，空值统一 `—`。
7. **21 个对话框统一骨架**：标题 40px、页脚 52px、标签列 112px、步骤条、提示条组件化。
8. **危险操作二次确认**：新增确认对话框设计（列出受影响对象 + 撤销建议 + 危险色主按钮）。

## 未包含（需要你确认后再做）

- **产品代码改造**：本次只交设计图与规范，`src/` 未改动。按你选择的方向，改造范围涉及 `base.css`（全部重写）、`App.ts` 骨架（标题栏/命令条/标签条）、`Ribbon.ts`、`icons.ts`、`InfoPanel.ts`、`DataGrid.ts` 与全部 21 个对话框。建议分两批：先主框架 + 核心页，再对话框。
- **深浅双主题**：当前只做浅色。tokens.css 已把语义别名与原始色阶分离，加深色主题只需覆盖 `--bg-*` / `--text-*` / `--border*` 与 `--n-*`/`--accent-*` 映射。
- **数据源品牌 logo 的处理**：设计图中连接树与类型选择器暂用线性 `database` 图标占位；实际实现应沿用仓库既有的官方品牌 logo（`tools/db_art/` → `dbIcons.ts`），线性的只用于其余图标。
