信息面板 · 对象头顶部重设计

针对表 / 列页信息面板顶部的红框区域：现状是「居中大图标 + 标题 + 副标题 + 一行连接引用」， 上下各留 20px 以上空白，红框里只有 TradeRecord、表、TiDB 三个信息点， 而右侧却还有三个只有图标的视图切换按钮。以下三个方案把这块区域改成「身份 + 规模 + 视图切换」的紧凑结构， 全部沿用 v2 令牌（面板宽 292px，字号 11 / 12 / 13 / 15）。

改动清单（A / B / C 共有）

  1. 连接引用从独立「引用行」并入顶部连接 chip（品牌 logo + 连接名），释放 28–40px 垂直空间，连接不再孤立成行。
  2. 对象头由「居中 48px 图标 + 标题 + 副标题」改为左对齐身份块：图标瓦片 + 15px 标题 + 类型 chip（数据源标识只出现在顶部连接 chip，不在图标上重复叠加）。
  3. 把散落在键值表里的规模字段（列数量 / 索引数量 / 外键数量 / 行）提升为指标带或胶囊，数字 600 字重 + 等宽数字，扫视即可比较。
  4. 三视图切换给出文字标签（A 整宽分段 / C 全宽 tab），不再只靠三个图标；只有 B 保留 icon-only，并把点击区放大到 24×20。
  5. 键值表去掉被提升的重复行，首屏能直接看到主键 / 数据长度 / 索引长度 / 引擎等真正需要的信息。
