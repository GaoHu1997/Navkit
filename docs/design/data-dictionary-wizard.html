1数据源连接下拉 + 数据库下拉 + 库信息徽标；切换连接时重读库列表与对象元数据。未选库 → 禁用「下一步」；库为空 → 空态「该连接下没有可访问的数据库」。SelectDatabase 下拉 + 库图标
2对象搜索框 + 三组树（表 / 视图 / 存储过程）复选；右侧「导出顺序」列表可移除。三类全不选 → 阻止前进并提示「请选择需要导出的对象」。TreeViewTables + 复选 + 搜索
3格式5 张格式卡单选；章节包含（表必选，视图 / 存储过程受格式约束）；Excel 可选工作表方式（所有表一个 sheet / 每表一个 sheet）。Excel / Word / HTML 时视图与存储过程自动禁用并置灰。DocTypeToggleStyle 单选组
