规格 · SPEC

落地要点（全部引用现有令牌，零新增色值）

面板容器：外边距 8px 10px、圆角 --r-3 6px、1px --border、--shadow-1 轻投影，与工具栏/表头明确分层。
面板头：高 38px，--bg-subtle 底 + 底边发丝线；左标题 12/600 + 计数徽标，右「清除」(ghost) + 「应用」(accent 主按钮)。
规则行：高 32px、行距 4px、圆角 6px；悬停 --bg-hover。行首 24px 拖拽手柄（grab），优先级圆标 19px，删除固定行尾。
方向开关：升/降序分段控件 26px，选中 --accent-50 底 + --accent-700，替代单键循环切换。
操作位置：主操作固定面板头右侧，永不在页面底部单开一行；重复操作（添加）留在列表尾部的虚线按钮。
空态：图标 + 标题/说明 + 主按钮横排，≤ 60px 高；禁用态按钮 opacity .45，不发灰到看不清。
可访问性：焦点环 2px --accent-500 offset 1px；拖拽排序保留 ↑↓ 键盘操作；每行 aria-label 含字段名与方向。
兼容：类名沿用 .filter-bar / .fb-pane / .filter-rows / .filter-actions 等契约，验收脚本选择器无需改动。
