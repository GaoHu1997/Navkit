字段图标 · 三方案

现有字段图标外层是一个占满画布的圆角方框，里面又套一张白色圆角卡片，缩小到 16px 后两层边框挤在一起，形成「框套框」，发灰、发脏、辨识度低。下面三案都保留同族的蓝色圆角底与扁平双色语言，但把内层边框去掉。

  • 外层方框 + 内层白卡 = 两层描边，16px 时只剩一圈灰边
  • 内部内容被白卡压缩，横线过短，看不出「字段/列」
  • 与索引 / 外键 / 触发器并排时显得又重又闷
方案 A

字段行

▸ 字段4

去掉内框，直接三行「字段行」，首行加重当表头。最干净、缩到 16px 仍是一条条清晰横线，和列表语义最贴。

方案 B

表头网格

▸ 字段4

内部改成表头 + 网格线，高亮首列代表被选中的字段/列。信息量更足，最像「表结构里的字段」，但缩小后格子略密。

方案 C

竖列卡片

▸ 字段4

彻底不要外层大框，字段卡片本身就是图标——单层描边，绝对没有套框。竖长比例一眼是「一列字段」，但会比同族图标略窄。
