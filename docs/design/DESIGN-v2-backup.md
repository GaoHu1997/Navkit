# NavKit 设计规范 v2 —— 精致桌面版

> 目标：保留三栏信息架构（数据库工具需要高密度与固定位置），
> 重做**视觉系统**与**交互状态**，消除 v1 中"六条横栏堆叠、三套图标语言、字号无层次"的不协调。
>
> 设计图：`docs/design/gallery.html`（可交互画廊） · 截图：`docs/design/shots/`

---

## 一、v1 的问题（为什么看起来不协调）

| 问题 | 表现 | v2 的解法 |
|---|---|---|
| 横栏过多 | 标题栏 + 菜单栏 + Ribbon + 标签条 + 页工具栏 + 查询工具栏 = **6 条**，约 180px | 菜单并入标题栏 → **4 条**：标题栏(38) / 命令条(46) / 标签条(34) / 页工具栏(34) |
| 图标语言冲突 | Ribbon 彩色伪 3D 图标、树扁平单色、工具栏细线稿，三套并存 | **一套 24 网格线性图标族**（1.75 描边、currentColor），Ribbon 彩色图标全部退役 |
| 字号无层次 | 9.6 / 10.5 / 11.2 / 13.2 / 13.6 五档挤在一起 | **五级字号**：11 / 12 / 13 / 15 / 18，每级职责唯一 |
| 状态色混用 | 选中、悬停、激活全部是 `#CCE8FF` | **状态分层**：hover 灰底、selected 强调浅底+强调文字、active 强调实底 |
| 分隔线混乱 | 1px 灰线 + 阴影 + 边框叠加，边界含糊 | **一种分隔**：1px `--border`；层次只靠底色与留白 |
| 信息面板平铺 | 20 行灰色 label/value，全 `--` 占位 | **分组卡片**：对象头 → 连接引用 → 分组信息；空值统一 `—` 且降级 |
| 网格密集 | 19.2px 行高、无悬停、无斑马、右对齐不彻底 | **28px 行高**、斑马底 `--n-25`、悬停/选中分层、数字列 `tabular-nums` 右对齐 |
| 对话框陈旧 | 34px 标题条 + 44px 页脚 + 130px 标签列 | 40px 标题 / 52px 页脚 / 112px 标签列，字段间距 12px 栅格 |

## 三、图标规范

- 视框 **24×24**，渲染 13 / 14 / 15 / 16 / 20 / 28px
- 描边 **1.75px**，`round` 端点与连接，`fill: none`
- **数据源一律使用官方品牌 logo**（`tools/db_art/` → `assets/db-logos/`，101 种）：
  连接树连接节点、类型选择器卡片、连接属性对话框、信息面板连接引用行
  - 已连接 / 可用 = 彩色；未连接 / 规划中 = `grayscale(1) + opacity .5`
  - 自定义 ODBC 为通用连接类型、无品牌标志 → 使用线性 `database` 图标，不造品牌图形
- 其余界面元素使用线性图标族，**按语义着色**（见 3.1）

图标族见 `assets/icons.js`（70+ 个）；品牌映射见 `assets/db-logos.js`。

### 3.1 彩色图标规范（v2.1 · 命令条具象图标）

**命令条使用具象填充图标**（`assets/pict.js` → `pictIcon(label, size)`）：24×24 网格、
以色块填充为主的原创图形，每个 2–3 色（主色 + 辅色 + 白色细节），圆角统一 2–2.5，
视觉重量一致。十二个入口的构成（全部原创，禁止描摹商业软件图标）：

| 入口 | 构成 | 颜色 |
|---|---|---|
| 连接 | 两个链接节点 + 绿色加号徽标 | 蓝 `#2f6fed` + 青 `#14b8a6` + 绿 `#22c55e` |
| 新建查询 | 文档（折角）+ 加号徽标 + 文本线 | 靛 `#6366f1` + 浅靛 `#c7d2fe` + 绿 |
| 表 | 数据表：深色表头 + 浅色格线 | 蓝 `#0284c7` / `#e0f2fe` / `#7dd3fc` |
| 视图 | 填充视窗 + 白色虹膜 | 青 `#06b6d4` + 白 + 深青 `#0e7490` |
| 函数 | ƒ 符号 + 尾点 | 紫 `#8b5cf6` + `#c4b5fd` |
| 用户 | 填充人物（头 + 肩） | 琥珀 `#f59e0b` |
| 其它 | 2×2 对象矩阵 | 蓝 / 青 / 琥珀 / 石板 |
| 查询工具 | 终端窗口 + 提示符 | 翠绿 `#10b981` + 白 |
| 备份 | 数据圆柱 + 白色上传箭头 | 绿 `#16a34a` + `#4ade80` + 白 |
| 自动运行 | 闹钟（双铃 + 表盘） | 红 `#ef4444` + `#fee2e2` + `#b91c1c` |
| 模型 | ER 三节点 + 连接线 | 靛 `#6366f1` + 青 `#14b8a6` + 紫 `#a855f7` |
| 图表 | 三柱 + 基线 | 蓝 / 橙 `#f97316` / 青 |

**使用规则**

1. 具象彩色图标**只用于命令条**等高权重入口；页工具栏 / 菜单 / 状态栏保持语义着色的线性描边图标（`ICON_COLORS`），两级信息密度分明
2. 树与信息面板的功能图标用 `ICON_COLORS` 语义色描边（无底色），如 表=天蓝、
   函数=紫、备份=绿；系统库（information_schema 等）固定 `--n-400` 灰
2. 树与信息面板的功能图标用 `ICON_COLORS` 语义色描边（无底色），如 表=天蓝、
   函数=紫、备份=绿；系统库（information_schema 等）固定 `--n-400` 灰
3. 选中/激活态不得改图标颜色：激活 = 白卡 + 强调描边（见 5.1），
   禁用 = `grayscale(1) + opacity .4`，禁止灰度滤镜叠加选中色
4. 色值纪律：新增具象图标必须与上表同饱和度带（S ≈ 70%，L ≈ 50–60），
   每个图标 2–3 色封顶，白色细节只用于挖孔与高光，禁止渐变填充
5. 图标 hover 上浮 1px（100ms ease-out），`prefers-reduced-motion` 时关闭

## 三·二、Logo 规范（v2.2 · 抽象图形，无字母）

NavKit logo 为**原创抽象几何构成**（见 `assets/logo.js`）——与 Navicat（渐变环）、
IDEA（渐变方）、Claude（星芒）同属"图形隐喻"路线，不依赖字母：

- 容器：32 网格圆角方形（rx 8.5），强调蓝渐变 `#3d7cf0 → #1f4fc0`（左上 → 右下）
- 图形：**三层等距数据层**（isometric stack）
  - 顶层青色 `#35d0e8` = 活动数据 / 连接
  - 中层白色 = 数据本体
  - 底层浅蓝 `#93c5fd` = 存储基座
  - 隐喻：在数据层之间穿行（NavKit = 导航 + 工具箱）
- 单色版：透明底 + `currentColor` 三层轮廓（1.9 描边），用于深色底、水印、低对比场景
- 使用：标题栏 20px（圆角随尺寸缩放）、关于对话框 56px、画廊品牌位 22px
- 禁忌：不给主版整体改色；最小 16px；禁止拉伸 / 旋转 / 外描边
- 完整规范见设计图「Logo 规范 · NavKit v2」（网格构造 / 最小尺寸 / 用法 / 禁忌）

## 五、组件规范

### 5.1 命令条（替代 Ribbon）

- 高度 46px，按钮 = 图标 20px + 标签 11px，竖排
- 按钮最小宽 60px，间距 2px，悬停圆角 6px
- **激活态**：`--bg-selected` 底 + `--accent-500` 图标 + `--text-accent` 标签
- **禁用态**：文字 `--text-disabled`，无悬停反馈（不做灰度滤镜）
- 分组用 1px 竖线（16px 高，上下 16px 留白）
- 带下拉的按钮：右下角 10px `chevron-down`

### 5.2 标签条

- 高 34px，标签顶部圆角 6px，标签间距 2px
- 活动标签：白底 + `--border` 左右上描边 + 下方 2px 白底"抹掉"分隔线
- 悬停：`--bg-hover`；未选中文字 `--text-tertiary`
- 关闭按钮 16px，悬停显示灰底；有未保存改动时显示强调色圆点

### 5.3 树

- 行高 26px，缩进 14px/级，箭头 16px，图标 18px
- 悬停 `--bg-hover`；选中 `--bg-selected` + 强调文字 + 600 字重
- 连接已连接：行尾 6px 绿点；分组显示对象计数（tabular-nums）

### 5.4 数据网格

- 表头 30px、`--bg-subtle`、600 字重、12px、粘性定位
- 行 28px、斑马 `--n-25`、悬停 `--bg-hover`、选中 `--bg-selected`
- 数字列右对齐 + `tabular-nums`；NULL 用 `--text-disabled` + 斜体
- 主键列强调色 600 字重
- 页脚 32px：左统计，右分页（首页/上页/页码/下页/末页）+ 刷新 + 更多

### 5.5 信息面板

三段式：
1. **对象头**：56px 圆角图标块（`--accent-50` 底 + 强调色图标）+ 15px 600 标题 + 11px 副标题
2. **连接引用**：图标 + 文本，12px
3. **分组信息**：`11px` 分组标题（字距 0.04em），`96px | 1fr` 两列键值，空值显示 `—` 并降级

### 5.6 对话框

- 标题 40px（`--bg-subtle` 底 + 13px 600 标题 + 右侧关闭）
- 选项卡：底部 2px 强调色指示条，12px
- 内容区 padding 16px，字段行：标签列 112px 右对齐 + 12px 间距
- 页脚 52px，按钮高 30px，主按钮强调实底，危险操作红色实底
- 遮罩 `rgba(20,26,33,.28)`，无模糊

### 5.7 菜单

- 最小宽 208px，padding 4px，项高 26px，圆角 4px
- 勾选项在图标列显示 check；快捷键 11px 右对齐灰字
- 悬停：`--bg-selected` 底 + 强调文字（图标同步变色）
- 二级菜单：右侧 12px `chevron-right`

### 5.8 状态栏

- 高 26px，11px 字，`--bg-chrome` 底 + 1px 顶边
- 左：统计/位置；右：视图切换（分段控件）+ 面板开关
- 视图切换：`--bg-sunken` 容器 + 活动项白底 + `--shadow-1`

## 八、可访问性

- 所有图标按钮必须带 `aria-label`（设计稿中体现为 `title`）
- 焦点环 2px `--accent-500`，`outline-offset: 2px`，不依赖颜色单独传达状态
- 正文对比度 ≥ 7:1（`#262e38` on `#ffffff`）；辅助文字 ≥ 4.5:1
- 尊重 `prefers-reduced-motion`（tokens 中已全局关闭动效）
- 网格键盘导航：方向键移动焦点单元格，Tab 离开网格
