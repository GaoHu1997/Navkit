# NavKit 设计规范 v4 —— 专业桌面数据库工具

> 目标：与主流专业 IDE / 数据库客户端同级的**专业感与可读性**。
> 原则：界面服从功能。每个像素都服务于「快速找到对象、快速读写数据、快速看清结构」。
> **唯一权威**：本文以实际实现为准（`src/styles/base.css` 与 `src/ui/*`、`src/dialogs/*`）反向更新，
> 取代旧版 `DESIGN.md`（v3）、`界面规格表.md`、`design/README.md` 三份散稿（合并记录见 §10）。
> 改动界面时**先改实现，再回写本文**；本文与实现不一致时，以实现为准。
> 范围：除数据源官方 logo（`src/ui/dbIcons.ts`，101 个品牌图标）外，全部界面元素由本规范约束。

## 1. 设计基调

三条不可妥协的规则：

1. **chrome 要安静**。标题栏、命令条、标签条、页工具栏、状态栏一律使用中性浅灰，永不使用彩色底。
   彩色只出现在两处：**数据源 logo** 和**强调色用于当前焦点**。
2. **内容面要白**。所有承载数据的区域（网格、编辑器、表单）是纯白 `--bg-surface`。
   层级靠发丝线（1px `--border`）区分，不靠阴影和粗边框。
3. **图标要有秩序**。同一家族（对象 / 操作）使用同一线性权重、同一网格、同一圆角端点。
   对象类可带分类色，操作类一律 `currentColor` 跟随文字。

对照更早版本解决的三个问题：命令条彩色图标互相打架 → 统一双色扁平族；
黄文件夹 / 满屏蓝表 → 石墨文件夹 + 分类色对象图标；对话框内联样式各自为政 → 全部令牌化。

## 3. 字体与数字

- 界面：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", system-ui, sans-serif`（拉丁数字取自 Segoe，中文回退雅黑）
- 等宽：`"Cascadia Mono", "JetBrains Mono", Consolas, "Courier New", monospace`
- 字号令牌 `--fs-11 / 12 / 13 / 15 / 18 / 22`，每级职责唯一：
  - 11 元信息 / 表头 / 状态栏 / 角标 / 行号
  - 12 chrome、菜单、表单、页工具栏、标签页、对话框字段

  - 15 区块 / 信息面板对象名、空态标题
  - 18 对话框大标题、欢迎页 / 批执行指标
  - 22 欢迎页主标题（极少）
- 行高：界面 `--lh-normal 1.5`（紧凑处 `--lh-tight 1.25`）；SQL 编辑器 21px 固定
- 所有数字列 / 计数 / 页码 / 进度 / 大小启用 `font-variant-numeric: tabular-nums`
- 中文不做 `letter-spacing`；仅小节标题 / 分组标题用 `0.04–0.05em`

## 5. 图标规范

### 5.1 两大家族

**对象类（扁平双色，24 网格，渲染 16–20px）**：浅色填充 + 中色调 1.3–1.6px 描边 + 白色细节。
用于命令条、树节点、标签页、信息面板、网格行图标、（新建连接）数据源类型卡片。

**操作类（单色线性，16–24 网格，1.4–1.6px 圆头）**：`stroke="currentColor"`。
用于页工具栏、菜单、状态栏、对话框按钮。颜色由容器决定，状态由 CSS 决定。

### 5.2 命令条图标（24 网格，双色扁平）

命令条共 **12 个入口**（顺序即渲染顺序）：连接 / 新建查询 ‖ 表 / 视图 / 函数 / 用户 / 其它 ‖ 查询 / 备份 / 自动任务 / 图表 / 关系图。
- 填充色 + 中调描边，与树 / 网格中同族图标同色（表=蓝、视图=青、函数=紫、用户=琥珀、备份/其它/自动任务=石墨、图表=多彩柱、关系图=蓝+石墨）
- 「新建」语义 = 右下 4.7r 绿色加号徽章（连接、新建查询）
- 禁用 / 未连接：`filter: grayscale(1)` + 40% 不透明度
- 图标源：`src/ui/pict.ts` 的 `PICT_ICONS`；`icons.ts` 通过 `pictDef()` 复用同一图标保证树 / 命令条联动一致

### 5.3 应用标志

三层等距菱形**透明悬浮堆叠，无背景容器**（透明底，可直接叠在任意底色 / 壁纸 / 标题栏上）：
顶层冰青（`#baf8fe → #97dce7`，基色 `#a9f6fe`）= 活动数据 / 当前连接，中层青瓷（`#cae6dd → #a9c9c3`，基色 `#bde0d5`）= 数据本体，
底层雾蓝（`#9db1d5 → #778eba`，基色 `#849dcb`）= 存储基座。三色取自品牌色卡
「Pastel Rainbow · 冰青」+「Celestial Sea · 青瓷 / 雾蓝」，明度阶梯 90 → 85 → 64；
中上靠**色相**（160° 对比顶层 187°）、中下靠**明度**（对比底层 64）双保险，缩到 16px 仍读得出三层。
每层必须带一条「同族加深」的细描边 —— 顶层 `#82becc`、中层 `#91aead`、底层 `#677ca6`，否则浅色中层在浅色标题栏、冰青顶层在深色任务栏上都会失去轮廓。层间 `feDropShadow`（`#2a3759`）形成纵深。

隐喻：NavKit = 导航 + 工具箱 —— 在数据层之间穿行。抽象几何，无字母依赖，不复刻任何具体产品标识。
20px 用于标题栏，48px 用于「关于」，16px 为最小可用尺寸；`size ≤ 24` 时描边加粗（0.9 → 1.2）、投影改「短而深」（dy 0.55 / σ 0.5 / 浓度 0.30）。
单色版用 `navkitLogoMono`（三层 `currentColor` 轮廓；顶层 100%、中层 82%、底层 62% 不透明度），用于水印与深色底；**使用处必须显式设置 `color`**。
禁止：拉伸、旋转、加回背景板、把描边改成异色。实现见 `src/ui/logo.ts`。

### 5.4 数据源品牌 logo

连接树、新建连接类型选择、连接属性等处一律使用 `src/ui/dbIcons.ts` 的官方品牌 logo（101 种，PNG/SVG/WebP 原图），
不使用线性图标替代；未连接 / 灰态使用 `_off` 灰阶变体。品牌色不参与 §2.4 分类色体系。

### 5.5 图标在信息面板 / 树 / 网格中的复用

- 信息面板对象头使用**线性单色**强调色图标（`InfoPanel.ts` 的 `LINEAR_KEY_BY_RES` 映射），底色 `--accent-50`。
- 树节点使用**双色对象图标**（`kindIcon()` / `dbCatalog`），数据库连接节点用品牌 logo，系统库用 `_off` 灰阶。
- 网格行 / 标签页图标与树同源（14–16px 对象图标），保证「同一对象在多处同一张脸」。

## 6. 组件规范

### 6.1 标题栏（36px，含菜单）
`--n-50` 底 + 1px 底边。左：logo 20 + 产品名 13/600 + 分隔线 + 内联菜单项（24 高，悬停 `--n-150` 4px 圆角）。
右：当前对象 12/三级色 → 全局搜索 / 设置 图标钮（28×24）→ **更新徽标**（见 §6.22）→ 任务中心图标（见 §6.20）→ 窗口钮（44 宽；关闭悬停 `#e81123` 红底白字）。
菜单已并入标题栏，不再单占一行。

### 6.2 菜单 / 右键菜单
菜单栏基础项：**文件 / 编辑 / 查看 / 工具**；查询页额外插入「查询」上下文菜单，菜单栏最右以纯文字项「**设置**」收尾（点击直接执行，不展开）。
- 浮层：白底 + 1px `--border` + 6px 圆角 + `--shadow-pop`，内边距 4px
- 项 26 高：18px 图标列（无图标时放勾选标记）→ 标签 → 快捷键（11px 三级色）→ 子菜单箭头
- **悬停 = 强调实底 + 白字**（图标列同步变白 85%）；禁用 = `--n-400` 且不可点；分隔线 1px `--n-150`，左右 6px 缩进
- 右键菜单同款浮层。树右键按对象类型分组（连接 / 数据库·模式 / 表 / 视图 / 过程·函数 / 组 / 默认），标签页右键（关闭族 / 刷新 / 复制），结果网格右键（复制 / 复制行等）。定义见 `src/ui/menu.ts`。

### 6.3 命令条（44px）
`--n-50` 底 + 1px 底边，左右内边距 8。
- 按钮竖直排列：图标 20 + 标签 11（间距 3），`min-width 58`，左右内边距 8，圆角 6
- 悬停：`--bg-pressed` 底，标签转主文字色
- 激活：`--accent-100` 底 + `--accent-700` 标签 600
- 带下拉：右上角 10px chevron（`--text-tertiary`，激活随强调色）
- 分组：1px × 16 竖线，左右 8 外边距
- 12 个入口见 §5.2

### 6.4 侧栏（连接树，264px，可拖 200–420）
`--n-50` 底，右侧 1px `--border`。
- 搜索框：白底 + 1px `--border-strong`，22 高；聚焦 = 强调描边 + 3px `--ring`
- 节点 24 高：展开箭头 16（折叠时 -90°）→ 图标 16 → 标签 13/`--n-700`
- 悬停 `--n-100`；选中 `--accent-100`，标签转主文字 + 500 字重
- 组名 600 字重；计数徽标 11px 三级色右对齐；已连接 = 6px 绿点
- 拖拽移动连接：`drop-before/after` 强调线、`dragging` 半透明、`move-picked` 左侧 3px 强调条
- 空态 / 未连接用 `_off` 灰阶图标

### 6.5 标签页（32px）
- 标签 12px，最大宽 220，上圆角 6；图标 14 + 标题 + 关闭钮（16）
- 悬停 `--n-100`；激活 = 白底 + `inset 0 2px 0 accent` 顶线 + 500 字重
- 脏标记：`•`（强调色，位于标题后）；关闭按钮仅悬停 / 脏时可见
- 标签条横向滚动，滚动条高 0（隐形）

### 6.6 页工具栏（32px）
白底 + 1px `--border-subtle` 底边。按钮 22 高：14px `currentColor` 图标 + 12px 标签，间距 6，悬停 `--n-100`。
主操作（运行、保存）用 `--accent-500` 实底白字。对象页动作多时允许横向滚动（`overflow-x: auto`）。

### 6.7 数据网格（核心）
- 表头 28 高：白底无填充，11–12px/600 三级色，1px 底边 `--border`；列间 1px `--border-subtle`
- 行 26 高：13px 主文字；斑马 `--n-25`；悬停 `--n-100`；选中 `--accent-100`（PK 单元格可加强）
- 数字列右对齐 + tabular-nums；NULL 用 11px 斜体 `--n-400`
- 列宽拖动：8px 命中区，悬停显示强调竖线 + 浮层数值标签
- 排序：表头内 9px 实心三角（currentColor），多列排序附优先级数字
- 脏单元格 `--warn-50`；删除行删除线 + 禁用色；行首标记列 / 复选框列固定
- 页脚 32 高：左操作组（新增 / 删除 / 提交 / 回滚 图标钮），右分页器（白底 1px 描边胶囊 + 页码输入 + 刷新 / 更多）
- 虚拟滚动：只渲染可视区域行；行号列灰字

### 6.8 查询编辑器
- 运行条 36：连接 / 库下拉 26 高 + 主色「运行已选择的」+ 停止 + 解释
- CodeMirror 6：13px mono / 21px 行高；活动行 `--accent-50`；行号栏 `--bg-subtle`
- 语法色：关键字 `#2b62d9` 600、字符串 `#1f9254`、数字 `#b54708`、注释 `--n-500` 斜体、类型 `#7a5af8`
- 补全浮层：26px 行高、最高 260px，白底 + 1px `--border` + 6 圆角 + `--shadow-pop`；名称 12px mono，行内灰字 11px；选中行 `--accent-500` 实底白字
- 补全备注：表 = 名称 + 灰色表备注；字段 = 名称 + 灰色类型 + `·` + 灰色备注；备注紧跟名称 8px，不建列轨道、不换行、溢出省略；**无备注整段不渲染**
- 备注仅在查询编辑器启用（`completionMode: "query"`），其它消费者保持基础模式

### 6.9 查询结果面板
- 结果页签 28 高：激活项强调色下划线 + 600 字重（消息 / 摘要 / 结果 / 剖析 / 状态）
- `qr-panel`：状态条（`--bg-chrome` 底 + 下边线，tabular）+ 工具区（控件 26 高，`--border-strong` 描边、4 圆角）+ 规则 / 字段区（`details` 折叠，最大高 240 滚动）+ 网格
- 列侧栏（`ColumnSidebar`，260px，右侧），搜索 + 「全选 / 恢复全部字段」，行 26 高
- 查询页底部状态行 36：连接选择器 + 强调色运行按钮
- 编辑器与结果区 2:1 分屏，中间竖向 splitter 可拖

### 6.10 信息面板（292px，可拖 240–400）
`--n-50` 底 + 左侧 1px `--border`。自上而下：

- 左「跳过此版本」，右「稍后 / 下载更新」。本弹窗的主按钮和勾选态例外使用 `--n-900` 深黑、次操作使用中性灰，焦点继续使用强调色；不改变共享对话框与其它界面。
- 检查中 / 已是最新 / 发现新版本 / 下载中 / 可安装 / 错误复用同一状态骨架；下载显示进度，允许后台执行；错误就地提示并可重试。最小化只折叠本弹窗，可还原；Escape 关闭、焦点回到触发器。

- 启动自动安装安全门：自动授权开启、成功下载记录存在、版本未跳过、后端 ready 且路径一致，才调用既有安装接口；先消费记录避免失败循环。无记录的存量就绪包不自动安装。运行中无自动安装，启动失败继续当前版本并显示可关闭提示；下载与换名替换流程复用，自动安装额外在任何程序改名前以 64 KiB 缓冲重读暂存包并核 SHA-256，固定路径被其它版本替换时拒装。后台下载/就绪事件使旧检查回执失效，隐藏或移除聚焦控件时将焦点移到弹窗内可见操作。真实跨版本演练仍待现场验收。

## 8. 实现约定

- 所有颜色、字号、间距、圆角、高度必须引用 `src/styles/base.css` 的令牌，**禁止散落十六进制色值**（图标 body 内的固定双色除外）。
- 局部样式文件（`src/styles/*.css`、`src/ui/*.css`）只消费既有令牌，不新增色板；新增组件先复用 §6 的模式。
- 深色主题就绪：只消费语义令牌（`--bg-surface` / `--text` / `--border` …），不直接读中性阶值。
- 类名契约保持不变（`.ribbon` / `.tabstrip` / `.grid-*` / `.tree-node` / `.menubar` …），验收脚本依赖它们。
- `icons.ts` 的 `IconDef` / `svg()` / `iconSvgByName()` / `NAME_MAP` / `_off` 灰阶机制为稳定 API；重设计只替换 body。
- 组件文档与源码一一对应：`src/ui/*`（框架 / 面板 / 编辑器）与 `src/dialogs/*`（对话框）每个文件头注释指向本规范对应小节。

### 8.1 对象浏览与保存查询
- 表、视图、函数（含存储过程）、查询入口进入唯一的“对象”页（所有连接、数据库共用一个，永远固定在标签条第一个）；单击不同连接/数据库只就地切换内容，绝不新开第二个对象页。页内持续显示连接、数据库和类别。“新建查询”创建独立编辑器。
- 对象列、工具栏、右键与双击按类别适配；无选择禁用行操作，操作按钮统一普通样式，不用蓝底突出新建。查询列表只包含本库已保存 SQL，打开仅恢复文本、名称和归属，不执行 SQL。
- SQL 只有未保存编辑文本和数据库内已保存查询两种状态。保存必须明确选择有效连接和数据库，不代选第一个库；以稳定 ID 更新，另存为创建新 ID。对象页没有未归属查询或归属操作。旧版缺少保存位置的 SQL 保留原文，仅能作为未保存文本恢复，用户选库后才能显式保存为新的库内对象。
- 写盘失败就地显示错误并保留输入供重试；数据库只读不限制本地查询管理。未可靠支持的数据库能力禁用并说明。
