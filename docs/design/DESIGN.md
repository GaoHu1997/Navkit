# NavKit 设计规范 v3 —— 专业桌面数据库工具

> 目标：与主流专业 IDE / 数据库客户端同级的**专业感与可读性**。
> 原则：界面服从功能。每个像素都服务于「快速找到对象、快速读写数据、快速看清结构」。
> 范围：除数据源官方 logo（`src/ui/dbIcons.ts`，101 个品牌图标）外，全部界面元素重设计。
> 上一版（v2）备份已于 2026-11-11 随文档整理删除，历史差异见 git 记录。

---

## 1. 设计基调

三条不可妥协的规则：

1. **chrome 要安静**。标题栏、命令条、标签条、状态栏一律使用中性浅灰，永不使用彩色底。
   彩色只出现在两处：**数据源 logo** 和**强调色用于当前焦点**。
2. **内容面要白**。所有承载数据的区域（网格、编辑器、表单）是纯白 `--bg-surface`。
   层级靠发丝线（1px `--border`）区分，不靠阴影和粗边框。
3. **图标要有秩序**。同一家族（对象 / 操作）使用同一线性权重、同一网格、同一圆角端点。
   对象类可带分类色，操作类一律 currentColor 跟随文字。

对照 v2 解决的三个问题：命令条 12 个彩色图标互相打架 → 统一双色扁平族；
黄文件夹 / 满屏蓝表 → 石墨文件夹 + 分类色对象图标；对话框内联样式各自为政 → 全部令牌化。

## 5. 图标规范

### 5.1 两大家族

**对象类（扁平双色，16 网格）**：浅色填充 + 中色调 1.3px 描边 + 白色细节。
用于树节点、标签页、信息面板、网格行图标、数据源选择卡片。

**操作类（单色线性，16–24 网格，1.4–1.6px 圆头）**：`stroke="currentColor"`。
用于页工具栏、菜单、状态栏、对话框按钮。颜色由容器决定，状态由 CSS 决定。

### 5.2 命令条图标（24 网格，双色）

11 个入口：连接 / 新建查询 / 表 / 视图 / 函数 / 用户 / 其它 / 查询 / 备份 / 自动运行 / 图表。
- 填充色 + 中调描边，与树中同族图标同色
- 「新建」语义 = 右下 4.7r 绿加号徽章（连接、新建查询）
- 禁用 / 未连接：`filter: grayscale(1)` + 40% 不透明度

### 5.3 应用标志

三层等距菱形**透明悬浮堆叠，无背景容器**（透明底，可直接叠在任意底色 / 壁纸 / 标题栏上）：
顶层冰青（`#baf8fe → #97dce7`，基色 `#a9f6fe`）= 活动数据 / 当前连接，中层青瓷（`#cae6dd → #a9c9c3`，基色 `#bde0d5`）= 数据本体，
底层雾蓝（`#9db1d5 → #778eba`，基色 `#849dcb`）= 存储基座。三色取自品牌色卡
「Pastel Rainbow · 冰青」+「Celestial Sea · 青瓷 / 雾蓝」，明度阶梯 90 → 85 → 64：
中上与中下之所以都分得开，是因为中层同时靠**色相**（160° 对比顶层 187°）和**明度**（对比底层 64）双保险，
缩到 16px 也不会糊成两层。去掉背景板后，每层必须带一条「同族加深」的细描边
—— 顶层 `#82becc`、中层 `#91aead`、底层 `#677ca6` —— 否则浅色中层在浅色标题栏上、
冰青顶层在深色任务栏上都会失去轮廓。层间 `feDropShadow`（`#2a3759`）投影形成纵深。
隐喻：NavKit = 导航 + 工具箱 —— 在数据层之间穿行。抽象几何，无字母依赖，
不复刻任何具体产品的图形标识，只靠形状、层次与颜色传达含义。

20px 用于标题栏，48px 用于「关于」，16px 为最小可用尺寸；`size ≤ 24` 时描边加粗（0.9 → 1.2）、
投影改「短而深」（dy 0.55 / σ0.5 / 浓度 0.30），保证 16px 下三层仍有可辨的分隔线。
透明底的好处是同一套图形可自由落在浅色 / 深色 / 图片背景上，不必为每种底色再出一版。
单色版用 `navkitLogoMono`（三层 `currentColor` 轮廓；顶层 100%、中层 82%、底层 62% 不透明度），
用于水印与深色底；**使用处必须显式设置 `color`**。
禁止：拉伸、旋转、加回背景板、把描边改成异色。

## 6. 组件规范

### 6.1 标题栏
36px，`--n-50` 底 + 1px 底边。左：logo 20 + 产品名 13/600 + 分隔线 + 菜单项（24 高，悬停 `--n-150` 4px 圆角）。
右：当前对象 12/三级色 → 搜索/设置 28×24 图标钮 → 窗口钮 44 宽（关闭悬停 `#e81123` 红底白字）。

### 6.2 菜单
浮层：白底 + 1px `--border` + 6px 圆角 + `--shadow-pop`，内边距 4px。
项 26 高：18px 图标列（无图标时放勾选标记）→ 标签 → 快捷键（11px 三级色）。
**悬停 = 强调实底 + 白字**（图标列同步变白 85%）。禁用 = `--n-400` 且不可点。分隔线 1px `--n-150`，左右 6px 缩进。

### 6.3 命令条
44px，`--n-50` 底 + 1px 底边。按钮最小宽 58、上下居中、图标 20 + 标签 11、间距 3。
- 悬停：`--n-150` 底，标签转主文字色
- 激活：`--accent-100` 底 + `--accent-700` 标签 600
- 带下拉：右上角 10px chevron，激活态随强调色
- 分组：1px × 16 竖线，左右 8px

### 6.4 侧栏（连接树）
264px，`--n-50` 底，右侧 1px `--border`。
搜索框：白底 + 1px `--border`，22 高；聚焦 = 强调描边 + 3px `--ring`。
节点 24 高：展开箭头 16（折叠时 -90°）→ 图标 16 → 标签 13/`--n-700`。
- 悬停 `--n-100`；选中 `--accent-100`，标签转主文字 + 500 字重
- 组名 600 字重；计数徽标 11px 三级色右对齐；已连接 = 6px 绿点
- 空态禁用状态用 `_off` 灰阶图标

### 6.5 标签页
32px。标签：12px，最大 220 宽，`--r-3` 上圆角。
- 悬停：`--n-100`
- 激活：白底 + `inset 0 2px 0 accent` 顶线 + 500 字重
- 脏标记：标题后强调色圆点；关闭按钮仅悬停/脏时可见

### 6.6 页工具栏
32px 白底 + 1px `--border-subtle` 底边。按钮 22 高：14px currentColor 图标 + 12px 标签，间距 6，悬停 `--n-100`。
主操作（运行、保存）用 `--accent-500` 实底白字。

### 6.7 数据网格（核心）
- 表头 28 高：白底，无底色填充，12px/600 三级色，1px 底边 `--border`；列间 1px `--n-150`
- 行 26 高：13px 主文字；斑马 `--n-25`；悬停 `--n-100`；选中 `--accent-100`
- 数字列右对齐 + tabular-nums；NULL 用 11px 斜体 `--n-400`
- 列宽拖动：8px 命中区，悬停显示强调竖线 + 浮层数值标签
- 排序：表头内 9px 实心三角（currentColor），多列排序附优先级数字
- 脏单元格 `--warn-50`；删除行删除线 + 禁用色；行首标记列 40 宽
- 页脚 32 高：左操作组（新增/删除/提交/回滚 图标钮），右分页器（白底 1px 描边胶囊）

### 6.8 查询编辑器
- 运行条 36：连接/库下拉 26 高 + 主色「运行已选择的」+ 停止 + 解释
- CodeMirror：13px mono / 21px 行高；活动行 `--accent-50`；行号栏 `--n-50`
- 语法色：关键字 `#2b62d9` 600、字符串 `#1f9254`、数字 `#b54708`、注释 `--n-500` 斜体、类型 `#7a5af8`
- 结果页签 28 高：激活项强调色下划线 + 600 字重
- 补全浮层：26px 行高、最高 260px，白底 + 1px `--border` + 6 圆角 + `--shadow-pop`；名称 12px mono，行内灰字 11px UI / `--text-tertiary`；选中行 `--accent-500` 实底白字
- 补全备注：关键字/函数只有名称；表 = 名称 + 灰色表备注；字段 = 名称 + 灰色类型 + `·` + 灰色备注。备注紧跟名称 8px，不建列轨道、不加表头与分隔线，不换行、溢出省略；**无备注整段不渲染**，绝不出现「未设置备注」等占位
- 备注仅在查询编辑器启用（`completionMode: "query"`），表结构页等其它消费者保持基础模式

### 6.11.1 分页向导（数据同步 / 数据生成 / 驱动管理）

长表单一律拆步，禁止把多个主题塞进一页。三段结构：

**① 步骤条**（`--n-0` 底 + 1px 底边，padding 12/16）
- 每步 = 20px 圆形序号徽标 + 步名（12px）
- 当前步：强调色实底白字徽标 + 主文字 600
- 已完成：徽标转 `--ok-50` 底 + `--ok-500` 绿勾，可点击回退（悬停 `--n-100` 底）
- 步间轨道 1px `--border`；已走过的段转 `--ok-500` 55% 透明

**② 面板**（`--n-50` 底）
- 面板头：步名 13/600 + 一句说明 11px 三级色 + 右上 `N / M` 计数

**③ 页脚**（48px）

**实现**：`src/ui/Wizard.ts`。每步通过 `hint` 提供一句说明，`validate` 返回文案即拦截前进。

## 8. 实现约定

- 所有颜色、字号、间距、圆角、高度必须引用 `src/styles/base.css` 的令牌，**禁止散落十六进制色值**（图标 body 内的固定双色除外）。
- 深色主题就绪：只消费语义令牌（`--bg-surface` / `--text` / `--border` …），不直接读阶值。
- 类名契约保持不变（`.ribbon` / `.tabstrip` / `.grid-*` / `.tree-node` / `.menubar` …），验收脚本依赖它们。
- `icons.ts` 的 `IconDef` / `svg()` / `iconSvgByName()` / `NAME_MAP` / `_off` 灰阶机制为稳定 API；重设计只替换 body。

### 8.1 对象浏览与保存查询

- 表、视图、函数（含存储过程）、查询入口进入每连接复用的“对象”页；页内持续显示连接、数据库和类别。“新建查询”创建独立编辑器。
- 对象列、工具栏、右键与双击按类别适配；无选择禁用行操作，操作按钮统一普通样式，不用蓝底突出新建。查询列表只包含本库已保存 SQL，打开仅恢复文本、名称和归属，不执行 SQL。
- SQL 只有未保存编辑文本和数据库内已保存查询两种状态。保存必须明确选择有效连接和数据库，不代选第一个库；以稳定 ID 更新，另存为创建新 ID。对象页没有未归属查询或归属操作。旧版缺少保存位置的 SQL 保留原文，仅能作为未保存文本恢复，用户选库后才能显式保存为新的库内对象。
- 写盘失败就地显示错误并保留输入供重试；数据库只读不限制本地查询管理。未可靠支持的数据库能力禁用并说明。
