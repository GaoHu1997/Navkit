# 界面规格表 —— NavKit（以参考截图为版式依据）

> **测量方法**：对 14 张参考截图（2560×1381 PNG）做逐像素扫描（PIL），并在运行中的
> 实现窗口上以同尺寸截图做并排/差分核对（tools/compare.py）。
>
> **缩放判定（重要）**：截图为 **125% DPI 下的物理像素**。证据链：
> ① 本机即 2560×1440 屏、系统 DPI 120/96 = 1.25；② 1381 = (1440 − 59 任务栏)，
> 即窗口在 2560×1440 屏最大化；③ 全部文字墨迹高度 ÷1.25 后落在 YaHei UI 的标准
> 点数字号上（菜单 8pt、树/网格 10pt）；④ 标题栏 29 物理px ÷1.25 ≈ 23.2 逻辑px。
> 因此 **逻辑 CSS px = 截图物理 px ÷ 1.25**；实现窗口的逻辑尺寸为 2048×1105，
> 在 125% DPI 下物理渲染恰为 2560×1381，与截图 1:1。
> （初版曾误判为 1x 与 2x，均已在实现中纠正——见《差异清单》。）
