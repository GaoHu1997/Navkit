# NavKit —— 验收报告（验收 + 修复 + 复验一次性交付）

> 验收基准优先级：**参考程序运行态实测（14 张 2560×1381 实测截图）>
> docs/界面规格表.md（对截图逐像素扫描的实测值）> 任务书第二节旧规格**。
> 任务书第二节中的 22px/28px/260px 数值是更早一轮的「半尺寸」约定，
> docs/界面规格表.md 已明确判定其过时（「旧版实现按 ÷2 半尺寸构建，需要全量重建」）；
> 按任务书自身规则「若与 exe 冲突以 exe 为准」，本报告全部以 exe 实测值验收。
> 开发机为 125% DPI（AppliedDPI=120，已实测），实现采用「物理像素 ÷1.25 = CSS 像素」方案，
> 渲染物理像素与参考截图一一对应（tools/cmp1..cmp10 系列并排/差分截图为证）。

## 7. 绿色版使用说明

```
dist-portable/
├─ navkit.exe            ← 主程序（6.59MB，双击即用）
├─ MicrosoftEdgeWebview2Setup.exe ← WebView2 离线引导（仅系统缺失时双击一次）
├─ README-portable.txt          ← 说明文件
└─ data\                        ← 便携数据目录（首次运行自动生成子项）
   ├─ config.json               应用设置
   ├─ connections.json          连接与分组（密码 AES-256-GCM 加密）
   ├─ key.bin                   密钥（与 connections.json 一并拷贝即可迁移）
   ├─ favorites.json / recent.json
   ├─ logs\navkit.log    历史日志（工具→历史日志 可查看）
   └─ cache\
```

双击即用确认项：
- ✅ exe 与 data 同目录，整目录拷贝到 U 盘/其它电脑可继续使用；
- ✅ 运行期只写 ./data，不写 AppData、不写注册表；
- ✅ Win10 1803+ 一般已预装 WebView2，可直接运行；缺失时先双击引导程序安装一次；
- ✅ 连接密码加密存储；删除 key.bin 前请勿单独迁移 connections.json（否则无法解密）。
