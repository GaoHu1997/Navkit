# NavKit — 数据库管理工具

**连接数据库、浏览数据、编写 SQL、设计表结构，在一个桌面工作台中完成日常数据库工作。**

NavKit 是一款中文界面的桌面数据库客户端，面向开发、数据分析与数据库日常维护。通过左侧对象树定位数据库和表，在多标签页中处理数据与查询，并随时查看对象结构和属性。

![NavKit 数据工作台：对象树、分页数据网格与表信息面板](<assets/screenshots/data-browser.png>)

*数据工作台：左侧管理连接与对象，中间浏览表数据，右侧查看字段、索引、DDL 和表属性。*

## 能做什么

| 场景 | 主要功能 |
|---|---|
| 管理多个数据库 | 新建与测试连接、连接分组、拖拽排序、搜索对象、驱动管理 |
| 查看和整理数据 | 分页浏览、条件筛选、多字段排序、可见列设置、复制与数据编辑 |
| 编写和运行 SQL | 语法高亮、表和字段补全、选区执行、SQL 美化、代码段、查询结果导出 |
| 维护数据库结构 | 表结构设计、字段与主键设置、索引和外键信息、SQL 预览 |
| 搬运与备份数据 | CSV / JSON / SQL 导入导出、结构与数据同步、SQL 转储、备份与还原 |
| 理解和交付数据库设计 | 表关系图、字段与外键查看、Word / PDF / Excel / HTML / Markdown 数据字典 |

> 不同数据库的可用功能有所区别。连接目录中的类型或驱动入口，不代表该数据库的全部功能都已完成真实服务器验证。

## 重点功能与界面

### 1. 多数据源连接管理

把不同项目、不同环境的连接放在同一处管理，不必在多个客户端之间来回切换。

- 按分类浏览或搜索数据库类型，在连接向导中填写参数并测试连接。
- 使用文件夹整理连接，拖拽调整分组与顺序，重启后继续保留。
- 在驱动管理中配置所需驱动；部分类型提供直接下载入口。

![新建连接：按类别浏览数据库类型，搜索并选择数据源](<assets/screenshots/connections.png>)

**常用数据源**

| 类型 | 示例 |
|---|---|
| 常用关系型数据库 | SQLite、MySQL、MariaDB、PostgreSQL |
| MySQL 兼容数据源 | TiDB、OceanBase、PolarDB、TDSQL、Doris、StarRocks |
| PostgreSQL 兼容数据源 | openGauss、KingbaseES、HighGo |
| 分析型数据源 | ClickHouse |
| 扩展连接 | 通过适用的 ODBC / JDBC 驱动连接更多数据源，需满足对应驱动与运行环境要求 |

具体连接方式、可用操作与验证范围见[产品状态说明](<docs/completed/PRODUCT-STATE.md>)。

### 2. 数据浏览与编辑

打开表即可查看数据，同时了解它的结构，不必为每次查找都先写一条 SQL。

- 分页浏览记录，组合 AND / OR 条件筛选，并按多个字段设置排序优先级。
- 调整列宽和可见列，复制单元格或行，查看长文本等单元格内容。
- 在支持编辑的表中修改数据、添加或删除记录，再提交或撤销待提交改动；是否可写取决于连接权限与数据源能力。

首页截图展示了表数据与信息面板。右侧可切换表信息、DDL 和列信息，便于边看数据边核对结构。

### 3. SQL 查询工作台

从编写、执行到查看结果，在一个查询标签页中完成。

- 语法高亮与自动补全，结合当前连接中的表、视图、字段和别名提供提示。
- 界面运行按钮有选区时执行选区；`Ctrl + Enter` 固定运行全文，`Ctrl + Shift + Enter` 仅运行选区（无选区时不执行）。支持 SQL 美化、保存查询和常用代码段。
- 在下方查看结果与执行消息，按需导出结果；查询创建工具可选择字段、条件和排序，预览后插入 SQL，不会自动执行。

![SQL 查询：上方编写语句，下方查看结果，右侧使用常用代码段](<assets/screenshots/sql-query.png>)

支持手动事务的原生 SQLite / MySQL / PostgreSQL 连接，可在查询页开始事务、提交或回滚；具体语句与数据库条件有限制，不等同于所有数据源均支持。

### 4. 可视化表结构设计

在结构设计器中集中查看和调整字段定义，保存前先核对生成的 SQL。

- 查看和编辑字段名称、类型、默认值、是否允许 NULL、主键及注释。
- 通过字段、索引、外键、检查、触发器、选项等页签查看结构信息；可编辑范围取决于数据库类型。
- 使用 SQL 预览检查拟执行的结构变更。既有字段的物理顺序调整仅对支持的原生 MySQL / MariaDB 连接开放。

![表结构设计：字段属性、主键设置与结构页签](<assets/screenshots/table-designer.png>)

### 5. 数据同步与导入导出

按向导选择来源和目标，再核对映射与执行内容，让数据搬运过程更直观。

- 根据任务选择仅结构、仅数据或结构与数据一起同步。
- 核对源字段、目标字段与目标类型映射；支持的组合可比较结构或数据差异。
- 表级导出已接入 ClickHouse、通用 ODBC、HTTP/Native 数据源及 MongoDB；ClickHouse/ODBC 支持 CSV、JSON 和表数据 SQL，HTTP/Native 与 MongoDB 支持 CSV、JSON。MongoDB 的 JSON 使用 canonical Extended JSON 保留 BSON 类型。
- Redis 没有表级导出；MQTT 无标准历史存储，明确拒绝全量导出。Pulsar 导出的是目录/主题统计，etcd 与 ZooKeeper 导出单 key/znode 当前值，不是历史消息或递归备份。筛选、视图 SQL 和实库验证边界见[产品状态](<docs/completed/PRODUCT-STATE.md>)。

![数据库同步：执行前核对源字段、目标字段和类型映射](<assets/screenshots/data-sync.png>)

> 同步、增量比较与结构变更的支持范围并不相同，不能视为任意数据库之间都可无损迁移。MySQL 等数据库的 DDL 可能自动提交，不能保证整次任务都能回滚；重要操作前请先备份。

### 6. 表关系图

用关系图理解数据库中的表、字段与外键关联，适合熟悉已有项目和讨论数据结构。

- 从当前数据库读取表结构与外键，展示表卡片和关联连线。
- 搜索表、字段和外键，使用自动布局、缩放及适应画布整理视图。
- 在表结构图与工程 ER 图之间切换，查看和整理建模关系。

![表关系图：表卡片、字段、主键及外键连线](<assets/screenshots/er-diagram.png>)

### 7. 数据字典导出

把数据库结构整理成可分享的文档，减少手工维护字段说明的工作。

- 按数据源和对象选择需要导出的内容。
- 支持 Word、PDF、HTML、Markdown 和 Excel；Excel 可选择所有表放在一个工作表，或每张表单独一个工作表。
- Word / Excel / HTML 导出表结构；PDF / Markdown 还可包含视图与存储过程。

## 更多日常工具

- **备份管理**：创建和查看备份，执行还原，打开备份所在文件夹。
- **数据生成**：配置字段生成规则、预览样例，为开发和测试准备数据。
- **函数与存储过程**：查看定义，在支持的数据库中编辑或通过参数调用。
- **服务器监控与日志**：查看服务器状态、检索执行记录，辅助日常排查。
- **用户与权限管理**：在 MySQL 协议族连接中管理用户与权限，具体操作依赖服务器版本和账号权限。
- **自动运行与任务记录**：保存任务、查看运行历史；离线系统调度与高级任务链仍有未完成部分，不应视为无人值守能力已全部就绪。
- **连接配置同步**：通过 WebDAV 在设备间同步连接、分组与顺序，合并前预览差异；不传输数据库内容、SQL 文件或驱动附件。

## 开始使用

1. 打开 Windows 绿色版目录，运行 `navkit.exe`。系统缺少 WebView2 运行时时，先安装随包提供的运行时引导程序。
2. 点击「连接」，选择数据库类型，填写参数并测试连接。
3. 展开数据库或模式，打开表浏览数据；点击「新建查询」编写 SQL。
4. 需要调整结构时打开表设计器；需要搬运数据或交付文档时，使用对应向导。

**便携使用**：连接、设置、收藏、任务及备份等保存在程序同目录的 `data/` 中。迁移时复制整个目录；更新程序时保留 `data/`，不要删除其中的密码密钥。连接密码虽加密保存，仍应妥善保护整个便携目录。

## 使用前了解

- **写入能力因数据源而异**：只读连接、缺少权限或不支持的操作不会因界面存在入口就变为可用。
- **结构修改先备份**：DDL、重建表和数据同步可能包含不可整体撤销的步骤。
- **增量同步有范围限制**：当前增量同步仅面向 SQLite 双端原生通道，不应按通用跨库增量同步使用。
- **事务和取消有边界**：手动事务仅适用于受支持的连接与语句；查询停止与任务取消不代表所有数据库操作都可被立即中断。

更多能力边界与验证状态见[产品状态说明](<docs/completed/PRODUCT-STATE.md>)；开发、设计及维护资料从[文档索引](<docs/README.md>)进入。
